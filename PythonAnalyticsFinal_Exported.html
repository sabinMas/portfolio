#https://colab.research.google.com/github/amanchadha/aman-ai/blob/master/matplotlib.ipynb I used this notebook for key features I used in this code snippet like marker, as well as ax1 and ax2

#this should convert the date to year
pharmaSales_df['Year'] = pharmaSales_df['Date'].dt.year
#this should hopefully aggregate the data by year
pharma_sales_by_year = pharmaSales_df.groupby('Year')['Sum_Opioid_Related_Sales'].sum().reset_index()

#here I aggregate the 'all' opioid deaths to groupby yeara just like above
opioid_deaths_by_year = opioids_df.groupby('Year')['All'].sum().reset_index()

#I learned how to merge the datasets using this notebook, I figured it would be possible due to SQL and other programs having merge options
# https://colab.research.google.com/github/jakevdp/PythonDataScienceHandbook/blob/master/notebooks/03.07-Merge-and-Join.ipynb
comparison_df = pd.merge(opioid_deaths_by_year, pharma_sales_by_year, on='Year')

# this should create the main figure and subplot allowing the 2 plots within one figure
fig, ax1 = plt.subplots(figsize=(12,6))

# this will handle the opioid deaths on the left side
sbrn.lineplot(data=comparison_df, x='Year', y='All', marker='o', ax=ax1, color='red', label="Opioid Deaths")
ax1.set_ylabel("Opioid Deaths", fontsize=13, color='red')
ax1.tick_params(axis='y', labelcolor='red')

# this should hopefully be the second y axis showing the pharmaSales data
ax2 = ax1.twinx()
sbrn.lineplot(data=comparison_df, x='Year', y='Sum_Opioid_Related_Sales', marker='s', ax=ax2, color='blue', label="Pharma Sales")
ax2.set_ylabel("Pharma Sales ($)", fontsize=13, color='blue')
ax2.tick_params(axis='y', labelcolor='blue')

plt.title("Comparison of Opioid Deaths and Pharmaceutical Sales Over Time", fontsize=16)

With even my idea of pharmaceutical sales increasing over-time being wrong we see that even when sales dropped the opioid epidemic is still on the rise. Initially I questioned if Opioid deaths would increase as sales increased? I believe it is safe to say that although the first 3 years are almost parallel in a rising slope, when the pharmaceutical sales drops and gets shakey, the opioid deaths continued to steadily rise. The pharmaceutical sales rates dropping is likely due to more holistic practices becoming 'mainstream' or political changes¶
